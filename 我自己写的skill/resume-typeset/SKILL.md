# 简历排版（Resume Typeset）

输入：简历内容（任何文本形式）。输出：一页 A4 PDF，视觉风格严格复刻爆款校招简历。

## 流程

1. **填模板**：复制 [assets/template.html](assets/template.html) 到工作目录，把 `{{内容}}` 替换为按模板注释里的组件写的正文。组件清单和用法都在模板的注释块里（用完删掉注释）。不要改 CSS——所有视觉参数是从原版 PDF 逐 span 逆向的精确规格，改了就不像了。
2. **渲染**：`bash scripts/render.sh <input.html> <output.pdf>`（无头 Chrome，脚本会报告页数）。
3. **压一页**：目标是**一页排满**。超出一页时按顺序试：删内容（弱条目一行带过或删除，别舍不得）→ 微调 `.page` 的 padding 和 `li` 的 margin-bottom（±1-2px 级别）→ 行高 1.6 降到 1.5（下限）。不到万不得已不缩字号。内容确实撑得起两页时（资深候选人），两页也成立，但每页都要排满。
4. **视觉验收**：用 PyMuPDF 把成品第一页渲染成 PNG 自查（`page.get_pixmap(matrix=fitz.Matrix(2,2))`），确认：中西文字体混排正确（西文应是衬线）、分节线全宽、灰带行日期右对齐、没有孤行溢出。然后把 PDF 发给用户。

## 排版原则（来自原版的设计意图）

- **加粗策略**：只加粗数字、热词、极值词——扫读时眼睛只落在信号上。整句加粗是错的。
- **密而不乱**：这个风格靠高信息密度 + 清晰层级立住。留白多了反而露怯。
- **信息缺口**用 `<span class="todo">` 黄色高亮标出，让缺口在视觉上无处可藏；终稿必须清零。
- 图标用 emoji 即可（📞 ✉️ 💬 👤 🐙 🎓），宽度由 `.ico` 统一。
- 链接真实可点（`<a href>`），可验证锚点是这个风格的信用基础。

## 依赖

macOS + Google Chrome（无头渲染）。验收步骤需要 `pymupdf`（`pip3 install pymupdf`）。
