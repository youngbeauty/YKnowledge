# 它是什么

DeepSeek Harness（命令名 `dsh`）是 DeepSeek 在 2026-08-13 开源的 Agent 运行时。MIT 协议。仓库：<https://github.com/deepseek-ai/deepseek-harness>。官网：<https://deepseek.com/harness/>。

官方公式：

```
Agent = 模型 + Harness
```

聊天框只有模型。Claude Code / Codex / Cursor 是「模型 + 一套焊死的干活系统」。dsh 把这套干活系统拆开开源了。

底下是 [Cordis](https://github.com/cordiverse/cordis) 插件内核。模型、工具、Skill、会话、沙箱、存储、循环、调度、UI **全是插件**。不改源码，改 `cordis.yml` / patch 就能换。两条设计原则：

1. 一切皆插件
2. 每一次运行都有迹可循（模型看见的一切写入只追加的 session 日志，可回放、分叉、检索）

V4-Flash 的公开 Code Agent 基准，官方就是用这套 harness 的「极简模式」跑的。同一只 DeepSeek 换别的壳，成绩能差一截。dsh 是给它量过的那双鞋。

## 它不是什么

- 不是新模型。默认接 DeepSeek API，也能接 Anthropic / OpenAI / 任意 OpenAI 兼容端点 / 本地小模型。
- 不是再做一个 Claude Code。开箱能当编程 Agent 用，真正定位是底板。
- 不是 HenryZ838978/deepseek-harness（那是第三方 V4 协议适配器）。
- 现在不是稳定产品。README 写明会有破坏兼容性的变更。别上生产。

## 开箱能干什么

选好工作区之后：

- 读、搜、改仓库（`read` / `write` / `edit` / `glob` / `grep` / `str_replace_editor`）
- 跑 shell（macOS/Linux 是 `bash`，Windows 有 `pwsh`），长任务可丢后台
- 开持久终端、搜网页、抓页面
- 问你选择题；先写计划再动手（Plan Mode）
- 开子 Agent、后台 job、工作流、Ralph 循环
- 加载 Skills（`SKILL.md`）、接 LSP、查历史会话
- 危险操作先审批；新会话默认只能改工作区（`workspace-write`）
- 通过 SDK 可以把 Claude Code / Codex 当子 Agent 喊进来
- MCP 客户端随包装了，**默认关**（每个 MCP 命令都是沙箱外的可信代码）

## 四种模式

开新会话时选 preset：

| 模式 | 官方名字 | 什么时候用 |
|---|---|---|
| 标准 | Standard | 日常写代码。完整工具集 |
| PTC | Code mode | 模型写一段 TypeScript，一次编排多步工具调用（并行、少往返） |
| 极简 | Minimal | 评模型，或只要「持久 bash + 编辑器」 |
| 创造 | Creator | 改 harness 自己、热挂插件、组新 preset |

环境变量 `DSH_TOOLS_MODE` 可选 `native` / `code` / `both`。

## 三种入口

| 入口 | 命令 / 方式 |
|---|---|
| Web UI | `npx @deepseek-ai/dsh web` → `http://127.0.0.1:3080`（故意不支持 `0.0.0.0`） |
| Headless 一次性任务 | `npx @deepseek-ai/dsh --profile headless "跑测试并修失败"` |
| Python SDK | `pip install deepseek-harness-sdk`（内置 runtime，不需要系统 Node） |

还有 ACP（给编辑器 / 自动化）、自己写插件、`dsh plugin` 装社区组合包。

## 数据在哪

默认本地优先。对话、工具记录、API Key 在 `$DSH_HOME`（密钥在 `$DSH_HOME/.credentials.yaml`）。官方说明：不经你同意不会上传。你主动接外部模型 / MCP 时，数据归对面管。遥测默认关。
