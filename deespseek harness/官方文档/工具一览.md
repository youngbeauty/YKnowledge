# 工具一览（浓缩）

官方完整 schema 在仓库 `docs/tool-catalog.zh.md`。这里只留模型能看见的名字，方便扫。

标准模式大致会用到下面这些。极简模式只留持久 `bash` + `str_replace_editor`。PTC 模式额外用 `run_code` 编排。创造模式再加运行时检查 / Cordis 工具（需显式启用）。

| 工具 | 干什么 |
|---|---|
| `read` / `write` / `edit` / `read_image` | 读、写、改文件；读图要模型声明图像输入 |
| `glob` / `grep` | 找文件、搜内容（自带 ripgrep，不用本机装 `rg`） |
| `str_replace_editor` | 查看 / 创建 / 字面量替换 / 按行插入 |
| `bash` / `pwsh` | 跑命令。可 `run_in_background`，用 `job_*` 收尾 |
| `terminal_*` | 持久 PTY（open / send / read / close / list / signal） |
| `web_search` / `web_fetch` | 搜网页、抓页面（fetch 要组合里启用） |
| `ask_user_question` | 问你选择题，卡住等答案 |
| `exit_plan_mode` | 交计划给你批，批完退出规划模式 |
| `todo_write` | 会话内待办清单 |
| `skill` | 加载某个 Skill 的完整说明 |
| `subagent` / `subagent_fork` | 开子 Agent（可继续 / 一次性） |
| `list_agents` / `send_message` / `interrupt_agent` / `report` | 管后台子 Agent |
| `job_list` / `job_output` / `job_kill` | 管后台任务 |
| `create_goal` / `get_goal` / `update_goal` | 同会话 Goal |
| `schedule_create` / `schedule_list` / `schedule_delete` | 会话内定时后续（需启用） |
| `workflow` / `ralph` | 工作流；Ralph 是每个 round 换全新子会话 |
| `lsp` | 问语言服务器 |
| `session_search` 等 | 检索历史会话（需启用） |
| `run_code` | PTC：模型写一段 TS，一次调多只工具 |
| `mcp__<server>__<tool>` | 外部 MCP 桥过来的工具 |

权限默认 `workspace-write`。`danger-full-access` 绕过隔离。Python SDK 自带的 minimal 组合默认就是全开，只在可丢目录里跑。
