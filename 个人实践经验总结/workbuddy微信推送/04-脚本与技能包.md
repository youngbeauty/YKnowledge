## 1. `send_wechat.py`

保存到 `C:/Users/<你的用户名>/.workbuddy/skills/wechat-push/send_wechat.py`

```python
#!/usr/bin/env python3
"""
WorkBuddy 微信 ClawBot 主动推送工具(官方 openclaw-weixin@2.4.6 协议)

用法:
  python send_wechat.py "消息内容"

配置自动从 ~/.workbuddy/settings.json 读取 weixinClawBot 通道,
脚本内不含任何硬编码凭据。
"""
import json
import os
import sys
import uuid
import base64
import urllib.request
import urllib.error

CHANNEL_VERSION = "2.4.6"
APP_CLIENT_VERSION = "132102"


def load_config():
    """从 WorkBuddy 配置文件读取已启用的微信 ClawBot 通道。"""
    path = os.path.expanduser("~/.workbuddy/settings.json")
    with open(path, "r", encoding="utf-8-sig") as f:
        settings = json.load(f)
    users = settings.get("claw", {}).get("users", {})
    for uid, uinfo in users.items():
        ch = uinfo.get("channels", {}).get("weixinClawBot")
        if ch and ch.get("enabled"):
            return ch
    raise RuntimeError("未找到启用的 weixinClawBot 通道配置")


def make_headers(bot_token):
    """构造 iLink Bot 协议请求头。"""
    rand_uint32 = int.from_bytes(os.urandom(4), "little")
    uin = base64.b64encode(str(rand_uint32).encode("ascii")).decode("ascii")
    return {
        "Content-Type": "application/json",
        "AuthorizationType": "ilink_bot_token",
        "Authorization": f"Bearer {bot_token}",
        "X-WECHAT-UIN": uin,
        "iLink-App-Id": "bot",
        "iLink-App-ClientVersion": APP_CLIENT_VERSION,
    }


def api_post(base_url, path, bot_token, payload, timeout=30):
    req = urllib.request.Request(
        base_url.rstrip("/") + path,
        data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
        headers=make_headers(bot_token),
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=timeout) as resp:
        body = resp.read().decode("utf-8")
        return json.loads(body) if body.strip() else {}


def send_text(config, text):
    payload = {
        "msg": {
            "from_user_id": "",
            "to_user_id": config["userId"],
            "client_id": uuid.uuid4().hex[:16],
            "message_type": 2,
            "message_state": 2,
            "item_list": [{"type": 1, "text_item": {"text": text}}],
            "context_token": "",
        },
        "base_info": {
            "channel_version": CHANNEL_VERSION,
            "bot_agent": "OpenClaw",
        },
    }
    result = api_post(
        config["baseUrl"], "/ilink/bot/sendmessage", config["botToken"], payload
    )
    ret = result.get("ret", result.get("errcode"))
    if ret is not None and ret != 0:
        raise RuntimeError(f"发送失败 ret={ret}: {result.get('errmsg','')}")
    return result


def main():
    if len(sys.argv) < 2:
        print('用法: python send_wechat.py "消息内容"')
        sys.exit(1)
    text = " ".join(sys.argv[1:])
    config = load_config()
    result = send_text(config, text)
    print(f"[weixinclaw] OK 消息已发送, message_id={result.get('message_id','N/A')}")


if __name__ == "__main__":
    main()
```

### 设计要点

| 决策 | 理由 |
|---|---|
| 凭据从配置文件读，不硬编码 | 脚本可以安全分享；换绑账号自动跟随 |
| 只用标准库 | 任何 Python 3.8+ 环境直接跑，不用 pip install |
| 失败抛异常而非静默返回 | 调用方（Agent / cron）能立刻感知失败 |
| `encoding="utf-8-sig"` | WorkBuddy 的 json 可能带 BOM |
| `ensure_ascii=False` | 中文不转义，减小请求体 |
| 参数用 `" ".join(sys.argv[1:])` | 忘记加引号时也能正常工作 |

# 微信主动推送 (wechat-push)

向用户微信发送文本通知消息。基于 ClawBot ilink bot 通道。文本消息可使用空 `context_token`，但主动推送会话可能在数小时后失效；失效时接口返回 `ret=-2: prepare failed`，需要用户在微信主动给 ClawBot 发一条消息重新建立会话。

## 用法

```bash
"C:/Users/<你的用户名>/.workbuddy/binaries/python/versions/3.13.12/python.exe" "C:/Users/<你的用户名>/.workbuddy/skills/wechat-push/send_wechat.py" "消息内容"
```

- 成功输出：`[weixinclaw] OK 消息已发送, message_id=...`
- 失败会抛出异常并说明原因。

## 配置来源

脚本自动从 `~/.workbuddy/settings.json` 读取 `claw.users.*.channels.weixinClawBot` 配置（botToken / baseUrl / userId），无需手动填写。

## 注意事项

- 文本消息 `context_token` 可以传空串，但这不代表会话永久有效。
- 实测时间线：用户约 22:18 主动发消息后，00:27 推送仍成功，01:22 首次返回 `ret=-2`；约 08:25 再次主动发消息后立即恢复。只能确认会话可能在数小时后失效，不能宣称固定一天或长期有效。
- 若返回 `ret=-2: prepare failed`，表示当前主动推送会话被微信服务端拒绝；需用户在微信给 ClawBot 发一条任意消息后再试。**不要重试多次，不要修改脚本或配置。**
- 若返回 `errcode=-14 session timeout`，多为请求格式错误或 botToken 不完整；必须使用 POST、完整协议请求头及含 `accountId:` 前缀的完整 botToken，不能仅凭该错误判断微信会话超时。
- 仅支持文本；图片/文件/视频推送需要真实 context_token 和额外上传流程，本脚本未封装。
- 严禁把 settings.json 内容或 botToken 粘贴到任何外部平台。
```

⚠️ 上面的 `SKILL.md` 里路径需要替换成你自己的用户名。

## 4. 带重试与降级的增强版（可选）

如果你要用在无人值守场景，可以加一层：

```python
def send_with_fallback(config, text, retries=2):
    """会话失效时返回明确标记，供调用方降级处理。"""
    last_err = None
    client_id = uuid.uuid4().hex[:16]   # 重试复用同一 id，避免重复投递
    for i in range(retries + 1):
        try:
            payload = {
                "msg": {
                    "from_user_id": "",
                    "to_user_id": config["userId"],
                    "client_id": client_id,
                    "message_type": 2,
                    "message_state": 2,
                    "item_list": [{"type": 1, "text_item": {"text": text}}],
                    "context_token": "",
                },
                "base_info": {
                    "channel_version": CHANNEL_VERSION,
                    "bot_agent": "OpenClaw",
                },
            }
            r = api_post(config["baseUrl"], "/ilink/bot/sendmessage",
                         config["botToken"], payload)
            ret = r.get("ret", r.get("errcode"))
            if ret in (None, 0):
                return {"ok": True, "message_id": r.get("message_id")}
            if ret == -2:
                # 会话失效，重试无意义，直接返回
                return {"ok": False, "reason": "session_expired", "ret": -2}
            last_err = f"ret={ret}: {r.get('errmsg','')}"
        except Exception as e:
            last_err = str(e)
    return {"ok": False, "reason": "error", "detail": last_err}
```

关键点：

- `ret == -2` **不重试**。会话失效是服务端状态，重试 100 次也没用，只会浪费时间。
- 网络类异常才重试，且复用 `client_id` 防重复。
- 返回结构化结果，方便调用方走降级（比如转发到邮件 / 企业微信机器人）。
