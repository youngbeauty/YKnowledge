# WorkBuddy 微信主动推送 · 完整配置指南

> 让 WorkBuddy（以及本机其他 AI Agent，如 Codex、Claude Code）能够**主动**向你的个人微信发送消息。
> 适用场景：定时提醒、任务完成通知、每日简报、监控告警。

---

## 这套方案解决什么问题

WorkBuddy 桌面端自带「微信 ClawBot」通道，绑定后你可以在微信里给它发消息、它回复你——这是**被动响应**。

但很多场景需要的是**主动推送**：

- 每小时提醒我起来走走
- 每天早上 7 点把未读邮件整理成摘要发到微信
- 脚本跑完了、监控出问题了，主动通知我

WorkBuddy 自带的「推送到微信」开关在部分版本 / 部分场景下投递不稳定。本指南给出一套**完全自主可控**的方案：直接调用微信 iLink Bot 协议发消息，任何 Agent、任何脚本、任何定时任务都能一行命令调用。

## 30 秒预览

配置完成后，任何地方一行命令即可推送：

```bash
python send_wechat.py "服务器磁盘告警：/dev/sda1 已用 92%"
```

输出：

```
[weixinclaw] OK 消息已发送, message_id=7491156072188354056
```

微信立刻收到。

## 重要安全提示

- `~/.workbuddy/settings.json` 中的 `botToken` 等价于**你微信账号与该 bot 会话的通行证**
- 严禁把 token、settings.json 内容粘贴到任何公开平台、聊天群、代码仓库
- 本指南中所有 token 均为示例占位符，实际使用请读取你自己的配置文件
- 分发本文档时，请确认已移除所有真实凭据
