# emilkowalski/skills

- 来源：[GitHub 仓库](https://github.com/emilkowalski/skills)
- 主题：UI、动效与前端设计
- 类型：多 Skill 公开仓库
- 当前状态：建议收录；本地尚未安装或审计

## 简介

这是 Emil Kowalski 面向设计师和工程师整理的 Skill 集合，目标是帮助 Agent 在界面决策、交互动效和原型制作上更有设计判断，而不是只把页面“做出来”。

## 主要内容

- animate：设计和实现更自然的界面动效。
- review-animations、improve-animations：审查并改进已有动画。
- find-animation-opportunities：寻找可以通过动效增强反馈的界面位置。
- animation-vocabulary：统一讨论动画的术语。
- apple-design、pick-ui-library、prototype：辅助设计参考、组件库选择和原型制作。

## 适合场景

- 产品原型和营销页的交互动效。
- 前端页面完成后的动效审查。
- 想让 Agent 在实现前先考虑节奏、反馈和视觉层次。

## 安装入口

    npx skills@latest add emilkowalski/skills

## 注意

动画 Skill 适合按项目启用。对信息型页面，先确认动效不会影响加载速度、可访问性或阅读效率。
