# kepano/obsidian-skills

- 来源：[GitHub 仓库](https://github.com/kepano/obsidian-skills)
- 主题：知识管理与本地资料
- 类型：Obsidian 多 Skill 仓库
- 当前状态：建议收录；本地尚未安装或审计

## 简介

这套 Skill 让兼容的 AI 编程助手能够理解和操作 Obsidian 的开放格式，适合处理本地 Markdown、Bases、Canvas 和网页资料。

## 主要内容

- obsidian-markdown：Obsidian Flavored Markdown，包括 wikilinks、embeds、callouts 和 properties。
- obsidian-bases：.base 文件中的视图、过滤器、公式和汇总。
- json-canvas：.canvas 文件中的节点、连线和分组。
- obsidian-cli：Obsidian CLI、插件和主题开发。
- defuddle：从网页提取更干净的 Markdown。

## 适合场景

- 整理本地 Markdown 知识库。
- 在 Obsidian 与 AI Agent 之间建立稳定的文件操作规范。
- 把网页资料转成可继续编辑的 Markdown。

## 安装入口

    npx skills add https://github.com/kepano/obsidian-skills

## 注意

它针对 Obsidian 的格式和工作流。即使文件是普通 Markdown，也应先确认 wikilinks、callouts、properties 等语法不会破坏现有知识库结构。
