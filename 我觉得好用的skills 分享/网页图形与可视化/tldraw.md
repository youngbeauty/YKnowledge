# tldraw

- 来源：[官方产品站](https://www.tldraw.com/)
- 参考：[官方 GitHub](https://github.com/tldraw/tldraw)
- 主题：网页图形与可视化
- 类型：在线白板 / 无限画布 React SDK
- 当前状态：工具参考，不是可安装 Agent Skill

## 简介

tldraw 是一个无限画布和白板产品，也提供 React SDK。它适合做流程图、可视化笔记、节点式工作流和带 AI 操作能力的画布产品。

## 主要能力

- 无限画布、几何图形、富文本、箭头和绑定。
- 图片、视频、导出以及运行时 Editor API。
- 自定义 shapes、tools 和 UI。
- 可通过 @tldraw/sync 实现多人协作。
- 官方文档提供 AI 读取和操作画布的集成模式。

## 适合场景

- 可视化知识库或流程图工具。
- 节点式 AI 工作流和白板产品原型。
- 需要自定义画布交互的 React 项目。

## 使用入口

- 在线使用：[tldraw.com](https://www.tldraw.com/)
- SDK 文档：[安装文档](https://tldraw.dev/installation)

## 注意

这是产品和开发 SDK，不是可以复制到 ~/.codex/skills 的 Skill。正式项目使用 SDK 前，应阅读官方授权说明和当前版本文档。
