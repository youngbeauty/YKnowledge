# ayghri/i-have-adhd

- 来源：[GitHub 仓库](https://github.com/ayghri/i-have-adhd)
- 主题：AI 输出风格与可访问性
- 类型：输出格式 Skill
- 当前状态：建议按需收录；本地尚未安装或审计

## 简介

这个 Skill 用“注意力友好”的方式约束 Agent 输出：先说行动和结论，再给清晰的编号步骤，减少冗长前言、重复复盘和客套收尾。它不要求使用者有 ADHD 诊断，核心是让回答更容易快速执行。

## 主要特点

- 先给结论或下一步行动。
- 使用短段落和编号步骤。
- 避免把真正要做的事埋在长篇解释后面。
- 通过 /i-have-adhd 开启，可用 stop adhd mode 或 normal mode 停止。

## 适合场景

- 任务很多、需要快速执行时。
- 希望 Agent 输出更短、更直接时。
- 给行动清单、排查步骤或操作指引做格式约束时。

## 注意

它主要改变表达方式，不会自动替用户调用其他工具或完成任务。长期启用前，建议确认它不会压缩掉你需要的背景、风险和来源说明。
